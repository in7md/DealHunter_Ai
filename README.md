# DealHunter AI 🚗💨

> نظام ذكي متكامل ومتطور لرصد، تحليل، وتقييم صفقات السيارات المستحوعة في مملكة البحرين لحظياً (Real-Time)، مدعوم بالذكاء الاصطناعي ومعالجة البيانات المتقدمة.

---

## 🌟 نظرة عامة (Overview)

**DealHunter AI** هو رادار رقمي مصمم خصيصاً لاقتناص أفضل فرص صفقات السيارات في السوق البحريني. يقوم النظام بسحب الإعلانات الحية من أبرز المنصات والمصادر (السوق المفتوح، يلا موتور، دوبيزل، إنستقرام، وغيرها)، ثم يمررها عبر محرك تقييم ذكي ومحسّن إحصائياً (IQR Median Pricing & Gemini AI) لاحتساب القيمة العادلة، هامش الربح المتوقع، ونقاط صفقة السيارة بدقة متناهية، وبثها مباشرة إلى واجهة مستخدم تفاعلية عصرية.

---

## 🚀 الميزات الرئيسية (Key Features)

* **🔄 رصد متعدد المصادر (Multi-Source Scraper):** سحب متزامن وآمن من أبرز منصات وحسابات السيارات في البحرين مع معمارية تناوب ذكية تتجنب الحظر (Rate Limits).
* **🧠 تحليل مدعوم بالذكاء الاصطناعي:** استخراج تفاصيل السيارات (الموديل، السنة، السعر، المواصفات) من النصوص الحرة المعقدة (مثل منشورات إنستقرام) باستخدام قدرات Gemini AI.
* **📊 محرك تسعير عادل (Smart Market Engine):** حساب الوسيط الفعلي للسوق مع تصفية الإعلانات الوهمية أو الشاذة (IQR Outlier Rejection) لضمان دقة أرقام الأرباح.
* **⚡ دفق حي لحظي (Live SSE Stream):** إرسال الصفقات واكتشافها فوراً على لوحة التحكم دون الحاجة لتحديث الصفحة.
* **📱 جاهز للهواتف كـ PWA:** يدعم التثبيت المباشر على شاشة هاتفك (أندرويد وآيفون) ليعمل كتطبيق مستقل بكامل الشاشة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Backend:** Python, FastAPI, Starlette, SQLite, BeautifulSoup, Playwright, Uvicorn.
* **Frontend:** Next.js (App Router), React, Tailwind CSS, TypeScript, Server-Sent Events (SSE).
* **AI & Parsing:** Google Gemini API.

## ⚙️ التشغيل المحلي (Local Development)

لتشغيل المشروع محلياً على جهازك، اتبع الخطوات التالية:

### 1. تشغيل الخادم الخلفي (Backend)

```bash
cd backend
python -m venv venv
# لنظام ويندوز:
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload

```

### 2. تشغيل الواجهة الأمامية (Frontend)

```bash
cd frontend
npm install
npm run dev

```

افتح المتصفح على الرابط: `http://localhost:3000`
